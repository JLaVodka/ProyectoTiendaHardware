# ProyectoTiendaHardware

## Descripcion:
### Este es un proyecto para simular una tienda en linea desde Windows WPF para demostrar y reforzar los conceptos aprendidos durante el semetre

## Características
Simulación funcional de las operaciones de una tienda de hardware
Lógica de negocio implementada bajo el paradigma de Programación Orientada a Objetos
Interfaz de escritorio construida con Windows Forms

## Tecnologías
C#,.NET, Windows Forms
